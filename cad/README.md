# CAD Models

Welcome to the Cyberdeck CAD folder. This directory contains all the 3D model files and design documentation for the project.

## File Structure

```text

├── README.md

```

## Current Model

### Screen Speaker Panel
- File: [Screen_Speaker_panel.step](./Screen_Speaker_panel.step)
- Status: Complete
- Description: Custom speaker panel for the cyberdeck enclosure

## How to Use

### Downloading a model
1. Click the file name above
2. Click the download button
3. Open the STEP file in your CAD software

### Recommended CAD software
- Fusion 360
- FreeCAD
- Solidworks
- Onshape

If you update a design:
1. Export a STEP file
2. Add it into this folder
3. Keep the filename clear and descriptive
4. Open a pull request with a short summary of the change
